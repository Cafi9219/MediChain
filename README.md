# MediChain: Blockchain-Based Secure Traceability & Verification System for Cadaveric Organ Transplantation

A full-stack, enterprise-grade Consortium Blockchain application built for secure cadaveric forensic intake, multimodal biometric validation, dynamic multi-organ surgical harvesting, **2 required approvals out of 3 specialists** multi-signature verification, and tamper-proof chain-of-custody oversight.

## 🏛️ Consortium Architecture & Nodes

The network operates as a **Private Consortium Blockchain** with role-based access control across 4 healthcare consortium authorities:

1. **🏥 Donor Intake & Consent Wing (`CIFV` — Cadaveric Intake & Forensic Verification Wing)**:
   - Deceased donor registration & forensic physical examination
   - Multimodal biometrics (facial portrait, fingerprint with conditional damage bypass, ocular/retinal scan with conditional damage bypass)
   - Family Next-of-Kin legal consent OR Medico-Legal police inquest documentation
   - Infectious disease screening & organ recovery eligibility certification
   - Autogenerated Unique Hexadecimal Identifier (e.g., `0x4F8B7A92`)
   - Mandatory **2 required approvals out of 3 specialists** before surgical recovery clearance

2. **🫀 Surgical Organ Recovery Suite (`SROPS` — Surgical Retrieval & Organ Preservation Suite)**:
   - Reads approved donors from the `CIFV` pool
   - Dynamic Organ Recovery Form: selecting $N$ recovered organs dynamically mounts $N$ organ specification cards
   - **Algorithmic Organ ID Generator**:
     $$\text{Organ ID} = \text{[Last 4 Hex Digits]} - \text{[Organ Code 01..08]} - \text{[4 Random Digits]}$$
     *(e.g., `7A92-01-4821` for Heart, `7A92-02-3580` for Cornea)*
   - Cross-clamp timestamps, preservation solutions (UW / Custodiol HTK), storage temperatures (4°C), QA specimen photos, and live preservation window countdown badges (`TimeStatusBadge`)
   - Mandatory **2 required approvals out of 3 specialists** before certification and dispatch to Central Admin

3. **🏛️ Central Regulatory & Audit Board (`CTORB` — Admin)**:
   - Real-time organ inventory & safe preservation window (`Cold Ischemia`) monitoring
   - Certified directory of all 9 medical & regulatory specialists (displaying **Name, Role, Department, and Public Key only**)
   - Full chain-of-custody audit logs and printable official certificates
   - **Audit Trail & Blockchain Explorer** with a plain-language **Timeline View** by default and a **Technical Detail View** for SHA-256 hashes, Merkle roots, and raw JSON inspection
   - Interactive **Tamper Simulation Tool** demonstrating instant cryptographic detection of unauthorized ledger modifications

4. **🚑 Recipient Transplant Center Network (`RTCN` — External Hospital)**:
   - Isolated from pre-allocation donor identity records under consortium privacy protocols (Recipient Hospital delivery receipt & ETA workflow scheduled in Batch 2 / Step 6)

## 🚀 How to Run the Project

### One-Click Launch (Windows)
Double-click `start-project.bat` in this directory. It starts the backend engine (`http://localhost:5000`), launches the frontend Vite server (`http://localhost:5173`), and opens the portal in your browser.

### Manual Launch
```bash
# Terminal 1: Backend Engine (Port 5000)
cd backend
npm install
npm start

# Terminal 2: Frontend Portal (Port 5173)
cd frontend
npm install
npm run dev
```

### Production Build Check
```bash
cd frontend
npm run build
```
