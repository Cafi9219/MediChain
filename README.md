# MediChain: Blockchain-Based Secure Traceability & Verification System for Cadaveric Organ Transplantation

A full-stack, enterprise-grade Consortium Blockchain application built for secure cadaveric forensic intake, multimodal biometric validation, dynamic multi-organ surgical harvesting, 2-of-3 threshold multi-signature verification, and tamper-proof chain-of-custody oversight.

---

## 🏛️ Consortium Architecture & Nodes

The network operates as a **Private Consortium Blockchain** with strict role-based access control. Direct inspection and ledger write access are restricted exclusively to the 3 authorized healthcare consortium authorities:

1. **🏥 Cadaveric Intake & Forensic Verification Wing (CIFV)**:
   - Deceased body registration & forensic examination
   - Multimodal biometrics (face portrait, fingerprint with conditional damage toggle, ocular/retinal scan with conditional damage toggle)
   - Family NOK legal consent OR Medico-Legal police inquest documentation
   - Infectious disease screening & harvesting viability certification
   - Autogenerated Unique Hexadecimal Identifier (e.g., `0x4F8B7A92`)
   - Mandatory **2-out-of-3 Specialist Signatures** before surgical recovery clearance

2. **🫀 Surgical Retrieval & Organ Preservation Suite (SROPS)**:
   - Reads verified cadavers from CIFV pool
   - Dynamic Organ Harvest Form: user enters $N$ organs retrieved $ightarrow$ dynamically mounts $N$ organ specification cards
   - **Algorithmic Organ ID Generator**:
     $$\text{Organ ID} = \text{[Last 4 Hex Digits]} - \text{[Organ Code 01..08]} - \text{[4 Random Digits]}$$
     *(e.g., `7A92-01-4821` for Heart, `7A92-02-3580` for Cornea)*
   - Cross-clamp timestamps, preservation solutions (UW / Custodiol HTK), storage temperatures (4°C), QA photos
   - Mandatory **2-out-of-3 Surgeon Signatures** before dispatch to Central Admin

3. **🏛️ Central Transplant Oversight Regulatory Board (CTORB - Admin)**:
   - Real-time organ inventory & cold ischemia duration clocks
   - Complete directory and public key registry of all 9 certified medical personnel
   - Full chain-of-custody audit logs and printable official certificates
   - Live **Consortium Blockchain Explorer** with Merkle tree inspector
   - Interactive **Tamper Simulation Tool** (demonstrates instant cryptographic detection of data alterations)

4. **🚑 Recipient Transplant Center Network (RTCN - External Hospital)**:
   - Quarantined in Phase 2 under consortium privacy protocols (direct blockchain inspection prohibited)

## 🚀 How to Run the Project

### One-Click Launch (Windows)
Double-click `start-project.bat` in this directory. It starts the backend engine, launches the frontend dev server, and opens your default browser at `http://localhost:5173`.

### Manual Launch
```bash
# Terminal 1: Backend Engine (Port 5000)
cd backend
npm start

# Terminal 2: Frontend Portal (Port 5173)
cd frontend
npm run dev
```
